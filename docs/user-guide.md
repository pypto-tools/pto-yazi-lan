# 服务器文件互传速查（pto-yazi-lan）

**使用前提**　从服务器 A 打开面板时，你在 A 上的账户需要能用 SSH 密钥登录服务器 B 的目标账户（默认同名）。这一次登录就能上传和下载。首次使用可运行 `pto-yazi-lan --check` 检查连接和两端目录权限。

1. **打开面板**　在 A 上运行 `pto-yazi-lan`。左栏是本机 A，右栏是对端 B。
2. **选接收目录**　按 `Tab` 切到接收文件的一栏。用方向键选择目录，按 `Enter` 进入，按 `Backspace` 返回上一级。
3. **复制文件或文件夹**　切回来源栏，把光标移到要传的文件或文件夹上，多项用空格勾选。**左栏按 `F5` 上传，右栏按 `F5` 下载**（也可按 `c`）。核对目标后按 `Enter` 开始，默认跳过已有的同名文件。要更新同名文件，在确认提示中按 `u`。
4. **查看进度**　底部显示进度和速率。按 `t` 展开传输列表，传输完成后按 `q` 退出。

**如果检查失败**

- **SSH 认证失败**　确认 B 上的目标账户已授权你在 A 上使用的 SSH 公钥。
- **目录不可写**　上传时换到 B 上可写的接收目录，下载时换到 A 上可写的接收目录。
- **主机身份验证失败或连接超时**　把 A 的主机名（运行 `hostname -s`）和完整报错发给管理员。
